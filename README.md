# Interactive ART

A modern, responsive business landing page designed to help businesses establish a professional online presence.

## 🎯 Project Overview

**Interactive ART** is a clean and user-friendly landing page created to showcase business services. It features a streamlined three-step working process, helping potential clients understand the transition from research to final results.

## 🚀 Technologies Used

- **HTML5** – Semantic structure.
- **CSS3** – Layout design powered by **Flexbox**.
- **JavaScript** – Dynamic site interactions.

## 📁 Project Structure

```text
/
├── fonts/        # Custom typography assets
├── images/       # Project illustrations and icons
├── JS/           # JavaScript logic files
├── style/        # CSS stylesheets
└── index.html    # Main entry point
```

✨ Key Features
Responsive Design: Optimized for all screen sizes (Desktop/Mobile).
Modern UI: Professional layout with a focus on readability and clear Calls to Action (CTA).
Clean Code: Well-organized folder structure for easy maintenance and scalability.
